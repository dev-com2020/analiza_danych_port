# Kurs: Analiza Danych i Uczenie Maszynowe w Pythonie

Ten kurs prowadzi krok po kroku przez nowoczesny proces pracy z danymi w Pythonie: od przetwarzania i eksploracji danych, przez wizualizację i statystykę, po wprowadzenie do uczenia maszynowego.

## Jak korzystać
- Każdy moduł to samodzielny plik Markdown z przykładami kodu w Pythonie.
- Zalecane środowisko: Python 3.10+, `numpy`, `pandas`, `matplotlib`, `seaborn`, `scikit-learn`, `sqlalchemy`, `psycopg2` (lub odpowiedni sterownik DB).
- Szybka instalacja: `pip install numpy pandas matplotlib seaborn scikit-learn sqlalchemy psycopg2-binary`.
